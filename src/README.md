# 星途科幻图书电商平台（毕设项目）

## 项目介绍

本项目是基于Vue3+TypeScript+Element Plus开发的科幻图书电商平台，包含前台用户端和后台管理端，实现了图书展示、购物车、订单、用户/图书/订单管理等核心功能，整体风格为科幻主题，符合毕设的功能与设计要求。

## 技术栈

- 前端框架：Vue3（Composition API + Setup语法糖）
- 类型校验：TypeScript
- 构建工具：Vite
- UI组件库：Element Plus
- 状态管理：Pinia（含持久化）
- 路由管理：Vue Router（含权限守卫）
- 网络请求：Axios（封装拦截器）

## 项目结构

src/
├── api/ # 接口封装（前台 / 后台 / 模拟数据）
├── assets/ # 静态资源（样式 / 图片）
├── components/ # 公共组件（预留）
├── router/ # 路由配置（前台 / 后台 / 权限守卫）
├── store/ # 状态管理（用户状态）
├── types/ # 类型定义（图书 / 用户 / 购物车）
├── utils/ # 工具函数（请求封装）
├── views/ # 页面视图
│ ├── front/ # 前台页面（首页 / 图书 / 购物车 / 登录等）
│ ├── back/ # 后台页面（图书 / 用户 / 订单管理）
│ └── 404.vue # 404 兜底页面
├── App.vue # 根组件
├── main.ts # 入口文件
└── env.d.ts # 环境变量类型声明

## 功能模块

### 前台（用户端）

1. 登录/注册：支持买家/卖家/管理员角色登录，表单验证
2. 首页：科幻主题首页，展示热门图书、分类入口
3. 图书列表：分类筛选、图书卡片展示、加入购物车
4. 图书详情：图书信息展示、购买数量选择、加入购物车
5. 购物车：商品增删改查、数量修改、总价计算
6. 个人中心（预留）：用户信息展示/修改

### 后台（管理端）

1. 图书管理：图书增删改查，支持新增/编辑/删除
2. 用户管理：用户列表展示、角色修改
3. 订单管理：订单筛选、状态修改（发货/取消等）
4. 权限控制：仅管理员可访问后台页面

## 运行步骤

1. 安装依赖：`npm install`
2. 启动项目：`npm run dev`
3. 访问地址：`http://localhost:3001`
