# 星途科幻图书电商平台 - 毕设答辩说明

## 1. 项目背景与意义

随着电商行业的发展，垂直领域的图书电商平台需求增加，科幻图书作为小众但高粘性的品类，需要专属的电商平台满足用户需求。本项目基于Vue3+TypeScript开发，实现了科幻图书电商的核心功能，既满足了毕设的技术要求，也具备实际的应用价值。

## 2. 核心技术选型理由

- Vue3：相比Vue2，Composition API更适合复杂逻辑的组织，Setup语法糖简化代码
- TypeScript：提供静态类型校验，减少运行时错误，符合企业开发规范
- Element Plus：成熟的Vue3 UI库，组件丰富，开发效率高
- Pinia：Vue3官方推荐的状态管理库，比Vuex更简洁，支持持久化
- Vite：比Webpack更快的构建工具，热更新速度快，提升开发效率

## 3. 核心功能实现思路

### （1）权限控制

- 基于Vue Router的前置守卫，判断用户登录状态和角色
- 未登录用户访问需要登录的页面（购物车/后台），自动跳转到登录页
- 非管理员用户访问后台页面，提示无权限并跳回首页

### （2）数据管理

- 模拟接口数据：前期无后端时，通过mock数据实现功能闭环
- Pinia状态管理：用户登录状态持久化，刷新页面不丢失
- Axios封装：统一处理请求/响应拦截，添加token、错误提示

### （3）科幻主题样式

- 深色背景+科技蓝为主色调，贴合科幻主题
- 渐变、阴影、发光效果增强科技感
- 响应式布局，适配不同屏幕尺寸

## 4. 项目可扩展方向

- 对接真实后端接口（如Spring Boot）
- 增加支付功能（对接支付宝/微信支付）
- 完善个人中心、订单详情等页面
- 添加图书搜索、收藏功能
- 优化移动端适配
